## Done (by finding)
- **R-AB M4** (UTH): while a bet is confirmed, chips, tools and felt spots are disabled with
  `uth.v2.reason.press_change_bet` ("Press Change bet first" / "Сначала «Изменить ставку»"). Only `~change` sends `clear`,
  and it loads the confirmed bet into the draft first. `UthScreen.edit` never sends `clear`.
- **R-AB M5** (UTH): the v0.1.2 hotfix clamp is back in pure `UthFlow`:
  `maxAnte = min((maxW − Trips)/6, (balance − Trips)/3)` and `maxTrips = min(maxW − 6·Ante, balance − 3·Ante)`.
  - `UthFlow.chip(denom, v)` greys the tray chips when the armed spot is at its cap, with the
    `uth.error.max_ante` / `max_ante_balance` / `max_trips` reason.
  - `UthFlow.add` clamps a chip to the cap and flashes the reason; Deal stays enabled.
  - `UthFlow.rebet` clamps Trips first, then the Ante.
  - Status line 2 reads "Right click: −1 chip · max Ante N" (new key `uth.v2.status.max_ante`).
  - An edit that applies as asked clears an old clamp flash.
- **R-AB m10**: `UthTableBlockEntity.buildPub` is the only server change. Seat hole cards are public only when the round is
  settled AND the segment is SHOWDOWN/RESULT, and never for a folded seat.
- **R-AB M3** (poker + UTH bank): both screens use the kit stepper (`chrome.stepper.set(...)`).
  - `PokerFlow.stepMinus` / `stepPlus` and the `UthFlow` equivalents give the − / + gates, disabled at the ends with
    `poker.v2.reason.stepper_min` / `stepper_max`. The hand-made stepper hits and the `~stepper` action are gone.
  - Poker presets: a `poker.preset` target over the stepper value, added in `layoutOverlay`. Click = next preset
    (½ pot, ¾, pot, all-in); scroll = − / +.
  - The ↑ / ↓ keys press the kit stepper.
  - During a turn there are ≤ 2 actions (Fold, Check/Call), the stepper and the Raise primary, as K2 requested.
- STRINGS (poker v2 / uth v2 subsections): `poker.v2.step_minus`, `step_plus`, `reason.stepper_min`, `reason.stepper_max`;
  `uth.v2.reason.press_change_bet`, `uth.v2.status.max_ante`. Then `gen_lang.py`; it writes CRLF on Windows, so I
  converted the files back to LF.
