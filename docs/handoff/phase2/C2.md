## Done (code written, NOT yet compiled)
- R-CDE M4 banner geometry: `RouletteLayout` gained `numbers` (the 37 number cells), `glyphBoxes()`, `bannerRegions()`
  (preference: even-money + call row band, then outside-bet band, then the wheel column, then the felt) and `bannerObstacles()`
  (number cells, glyphs, wheel, history caption + pills). The old `bannerRegion` field was removed. `RouletteScreen.layoutPlay`
  uses them through `chrome.banner.regions(...)`. This is the existing kit API; switch to K2a's `banner.obstacles(...)` after `git merge p2/k2`.
- Spectator banner: if the viewer has no bet, `resultBeats` shows `banner.show("17 RED", 0, SHOW_MS)` (`numberWord`: key `roulette.v2.result`
  + `roulette.v2.board.color.*`) at 400 ms. This uses the existing `ResultBanner.show(word,net,ms)`.
- DES P1 value pills: own stacks get a ValuePill while betting when there are 8 or fewer stacks; above that, the pill shows on hover
  or for 1.5 s after the bet is placed. The count is exposed as `RouletteScreen.valuePillsDrawn()` for tests.
- DES P1 Repeat during result: `RouletteFlow.View` has a new `rebetQueued` component; the old 16-arg constructor still works.
  RESULT primary = Repeat N **enabled**. Pressing it queues the slip (client-side) and skips the local result beats.
  `containerTick` sends `rebet` once the phase is betting, but only if the slip is empty and `can_rebet` is set.
  While queued, the primary is disabled with reason `roulette.v2.reason.rebet_queued`. There are no server or money changes.
- R-CDE m4 mode-off: `RouletteTableBlockEntity.serverTick` mode-off path clears the bots' virtual slips (no money involved) and their results,
  then calls `publishSync()` before returning. A test accessor `pubSentAtForTesting()` was added.
- Strings (roulette v2 subsection only): added `reason.rebet_queued`. RU text was shortened for `status.add_or_spin` (`Ещё фишки или спин`)
  and `reason.waiting_ready`. `gen_lang.py` was run.
- Tests written: `RouletteLayoutTest.bannerNeverCoversTheWinningCell` (37 numbers x all sizes, banner T1/T2/T3 + compact 200x20),
  `RouletteFlowTest.repeatIsLiveDuringTheResult`, `RouletteV2GameTests.modeOffPublishesIdleBoard` / `modeOffClearsBotStacks`
  (actions sent through `TableNetworking.receive`; casino mode is turned off synchronously for exactly one table tick).
