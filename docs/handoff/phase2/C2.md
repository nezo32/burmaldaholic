## Done
- **R-CDE M4: banner placement.** `RouletteLayout` has `numbers` (the 37 number cells), `glyphBoxes()`, `bannerRegions()` and `bannerObstacles()`.
  - Regions, in preference order:
    1. the even-money row plus the call-bet row, down to the felt bottom;
    2. the whole outside-bet band;
    3. the wheel column;
    4. the whole felt.
  - Obstacles: the number cells, the glyphs, the wheel, the "Last numbers" caption and the pills. They are registered through K2a `chrome.banner.obstacles(...)`.
  - K2a's compact 200×20 banner is used automatically when the large one does not fit (427×240).
- **Spectator banner.** A viewer with no bet on the spin sees `ResultBanner.show("17 RED", 0, SHOW_MS)`. It uses `RouletteScreen.numberWord` (`roulette.v2.result` + `roulette.v2.board.color.*`).
- **DES P1: value pills.** Every own stack gets a ValuePill while betting when there are 8 or fewer stacks. Above 8, a pill shows only on hover or for 1.5 s after the bet is placed. `RouletteScreen.valuePillsDrawn()` exposes the count for tests.
- **DES P1: Repeat during the result.** `RouletteFlow.View.rebetQueued` was added; the old 16-argument constructor is kept.
  - During RESULT the primary is `Repeat N` and enabled (gold).
  - A press queues the slip on the client and skips the local result beats.
  - `containerTick` sends `rebet` as soon as the phase is `betting`, only if the slip is empty and `can_rebet` is set.
  - While queued, the primary is disabled with the reason `roulette.v2.reason.rebet_queued`.
  - If the balance is short, the primary waits with "bets open in N s".
  - There is no server change and no money change.
- **R-CDE m4: mode-off publish.** `RouletteTableBlockEntity.serverTick` mode-off path clears the bots' virtual slips (no money is involved) and their results. It then calls `publishSync()` before returning, so the in-world board goes idle. A test accessor `pubSentAtForTesting()` was added. These are the only hunks in this block entity. No payout, settle or RNG code was touched.
- **ROOMY (cheap part).** `RouletteLayout` allows up to 5 rows of history pills (20) at `grid.roomy()`. The server history length is still the config value `historyLength` (default 12), so at most 12 pills are filled.
- **RU strings** (roulette v2 subsection only):
  - new `reason.rebet_queued` (EN "Repeat goes on when bets open" / RU "Повтор — с началом ставок");
  - RU `status.add_or_spin` changed to "Ещё фишки или спин";
  - RU `reason.waiting_ready` shortened.
  - `gen_lang.py` was run.
