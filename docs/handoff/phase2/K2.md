K2b:
- B1: letters and digits show the key cap (`H`, `1`). Vanilla has no `key.keyboard.h`. Named keys stay `key.keyboard.<name>`. `KeyMap.plateChar`; KitContractTest checks the named keys against the vanilla/our en_us.

- M8 + m6: acks are `{epoch, count}` per player with a random non-zero epoch per entry, written as `ack_epoch` and `ack`. An entry is pruned when a non-viewer leaves and by a 30 s sweep. The client re-bases on an epoch change, and also on a counter that went back (v0.1.3 fallback, for servers without epochs).
- M9: `expected = max(expected, lastAck) + 1` per send.
- M5: the held-key set swallows auto-repeat for chips, tools, primary, secondary, actions and the stepper. There is a `keyReleased` route in V2TableScreen and V2SceneScreen; the set is cleared on resize.
- m15: the seat header publishes offset by the position hash. A swallowed bot-header exception is logged once per class.
- m1: `BetGates.armDefault(chips, min[, balance], lastUsed)`; BetBar uses it.
- m13: `V2Draw.fit` cache (text, width, language; LRU 256) used by `left` and `centred`.
- DES2: the primary key plate is dark ink #3a2a0a with gold text and dims when disabled.
- DES roulette P2:
  - The primary has one disabled style, slate (`ui2/art.mjs` `button_primary.disabled` #3A4256; generated and checked).
  - The multi-spot readout caption is `On table` / `На столе`.
- DES3: RU strings `Фишки → ставка`, `Кликните поле` (EN `Click the layout to bet`, no placeholder), `Ставки: %s с`.
- DES5: the 1-px bar did not reproduce in the new 1080p shots; there is no stray bar under the balance in `0000_v2_kit_k2_bj_480_bet.png`. No code change; testers re-check.
