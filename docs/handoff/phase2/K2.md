Presses go to `Host.onGate("stepper.minus"|"stepper.plus", gate)`. A disabled press shows the reason and shakes. Scrolling over the value steps −/+. Keys go through `Stepper.idForKey`. It is always used at T1, and at T2/T3 when the full banner finds no free slot (`compact()`). `obstacles(List<Box>)` adds obstacles and is reset each relayout. Kit obstacles: the Dock hint strip.
- `V2Chrome.flash(targetId, reasonKey, args...)` flashes the reason and shakes the target 3 px. `shake(id)`, `shakeDx(id)` for felt targets. ActionRow, BetBar chips/tools and Stepper all honour the shake.
- `V2TableScreen.registerSettings(Predicate<BlockEntity>, Consumer<BlockPos>)`. The TopBar gear (`top.settings`) shows only when a provider applies (`hasSettings()`, overridable). The integrator's `topSettingsHook` is kept `@Deprecated` and acts as a provider for `BotTable` until W2 switches BotsClientModule over. Without a provider the gear no longer opens CasinoConfigScreen on tables.

The M9 counting is already implemented: `expected = max(expected,lastAck)+1`, and a state is answered only when `ack >= expected`. Accessors `expected()` and `epoch()`. The chrome reads `ack_epoch` from the state, but the server does NOT write it yet (that is K2b).
- `DockLayout.Spec.statusW` / `withStatus(w)`. B2 logic is already in the pure layout: compact actions, then `Dock.hintStrip()` (11 px above the Dock). The chrome still passes statusW = 0, so nothing changes visually yet.
- ui-v2.md §3/§4.1/§4.2 rows updated.
- New unit tests: `AckWatchdogTest` (epoch change, two outstanding, error, timeout, legacy) and `DockLayoutTest` (stepper slot at every size, statusW → compact → hint strip, all §11.1 sizes EN/RU).
