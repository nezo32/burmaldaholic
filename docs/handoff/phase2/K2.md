# RS (K2c): every-resolution UI (PHASE2B §2.3)

## Done
- `ViewportPolicy` (pure) replaces the old `Viewport.of` maths (the ≥ 540 doubling is gone):
  - the player's GUI scale is kept for 240–720 px high GUIs (≥ 320 wide);
  - below that it steps down; above 720 it steps up by the smallest whole m (never below 320 wide, so portrait windows keep a taller GUI).
- `Frame` caps the screen at ≤ 600 high and ≤ 16:9, centred, in whole px.
  - `Viewport` gains `ox, oy, frameW, frameH, guiOx/guiOy, windowX/windowY, framed(), room()`.
  - The old 4-arg constructor is kept, and `toWindow` is scale only.
- `Room` is ROOMY when the frame is ≥ 800 × 450. `TableGrid` lays out in the frame and has `room` / `roomy()`.
- Wiring:
  - `FitScaled.offsetX/offsetY` (default 0) and `currentOffset()`;
  - `FitScaled.applyViewport` sizes the screen to the frame;
  - `ScreenEntrance` and `FitScaled.push` translate by the offset;
  - `MouseHandlerFitMixin` returns `(gui − offset) / factor`;
  - V2TableScreen and V2SceneScreen report the offset.
- `V2Chrome` dims outside the frame (ink 86 %) and draws the new generated `core/v2/frame_edge` nine-slice (`tools/assets/modules/ui2`; gen + check + npm test green).
- Kit at ROOMY:
  - the action key plates stay (no compact for statusW while the minimum fits);
  - `SeatPlate.draw(g, font, box, name, line2, kind, bot)` draws a two-line plate when the box is ≥ 26 high.
- ui-v2.md D2, D3 and the new §3.7 (policy, matrix, ROOMY adoption checklist per game).
- Tests:
  - `ViewportPolicyTest`: 22 matrix cells including 1366×768 GUI 2/3, 1280×1024, 854×480, 2560×1080, 3440×1440; the player's scale kept for 240–720; smallest step up; whole GUI offsets, centred ±1; Dock betting/actions without overlap in every frame, EN/RU.
  - `FrameTest`.
  - `TableLayoutV2Test` updated to the new policy.
- Client test `ResolutionMatrixClientGameTests` (CGT=RS), run on 26.2 in one JVM together with the K class:
  - gallery at 1280×720 Auto → 427×240 k3 T1; 1920×1080 GUI 2 → 960×540 k2 ROOMY; 2560×1440 GUI 2 → 1280×720 framed 1067×600 (ox 106, oy 60) ROOMY; EN plus RU at the last two. Every viewport equals the policy, targets are inside the frame with no overlaps, and chip/primary clicks were made at real window px.
  - Framed real blackjack: Sit down clicked at window px 2198,1264 → the SERVER seated the player.
  - Shots: `.burmaldaholic-tools/shots/RS/` (report `p2b_rs_report.txt`).
