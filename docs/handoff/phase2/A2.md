## Done (finding IDs)
Baccarat:
- **R-AB m8, server.** `BaccaratTableBlockEntity.onAction` has `unbet_chip {box, amount}` → `unbetChip()`. It is refused
  (error, nothing moves) unless house betting is open and the box holds at least `amount`.
  - The chip goes back through core `refundPart(id, "", amount, release)`, the same path as roulette Undo. No
    PLAY_RESOLVED; nothing re-debited; release = worstCase(slip) − worstCase(rest).
  - What stays on Banker is snapped down to the step. A remainder below the minimum returns the whole box.
  - No payout, settle or draw code was touched. The only BE hunk is the new case plus `unbetChip`.
- **R-AB m8, client.** The pure `BaccaratFlow.chipBack(history, bets, box)` picks the chip.
  - Undo is ONE `unbet_chip` of the newest chip. Before, it was unbet + re-bet: two packets with a race.
  - Right-click on a box takes ONE chip (the last one put there, else the top disc), not the whole box.

  shoe, deck count or penetration changed). Never mid-round. Client state `shoe {size, dealt, left, cut, discard}` counts
  only cards ON THE FELT (`BlackjackBeats.publishedCount`, hole card included), so nothing drawn ahead leaks. Shoe saved
  as `burmaldaholic_blackjack_shoe` (saved data only; not in the update tag). `shoeRng()` = fair OddsService RNG.
