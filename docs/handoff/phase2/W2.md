# W2: in-world board kit (PAUSED, work in progress)

Branch `p2/w2`. WIP commit `c4cdbfa` on top of `4b888f4`.

## Done (code only; compiled, not run)
- **M6:** removed `BoardAwareTextDisplayRenderer` and the global `EntityRenderers.register(TEXT_DISPLAY…)`. Added the client
  mixin `bots/mixin/client/TextDisplayRendererMixin` (bots mixins json, `client` section). It hooks the TAIL of
  `DisplayRenderer.TextDisplayRenderer.extractRenderState(Display$TextDisplay, TextDisplayEntityRenderState, float)`.
  javap shows that descriptor in both the 26.2 and the 26.3 client jars. The logic is in `bots/client/BotTagVisibility`:
  bot plate + near a board table + camera distance ≤ `HoloScale.READ_RANGE`. The weak cache is cleared on disconnect.
- **UI-A step 5:** `BoardKit.interim()` is now empty (the blackjack and baccarat rows are deleted). `BoardKit.register`
  clears `PlateFrame` and `BoardStats` on disconnect.
- **blocksOverhang:** added `BoardGeometry.blocksOverhang(collisionTopY)` (`> FELT_Y − 0.05`). `BoardRenderer.blocked`
  uses the collision shape's max Y, so carpet and bottom slabs don't block. The "table at dx=±2" rule is kept.
- **Dealer obstacle:**
  - Added `BoardGeometry.dealerRect(Felt)` and `BoardRenderer.dealerRect(be)`.
  - `CardTableRenderer.dealerRect` adds the Hold'em / UTH community row.
  - The rect is projected as a plate obstacle. `PLATE_UP` is now 0.28 (y≈1.30).
  - Obstacles and anchors are now projected in perspective along the view ray (`HoloFrame.project`) instead of
    orthographically. This is the likely cause of plates covering the dealer row under a raised camera.
- **M7:**
  - New `PlateLayout.TablePlates` and `PlateLayout.resolveGlobal(list, margin)`, a pure greedy resolve by rank with a
    hysteresis margin against other tables.
  - New client `PlateFrame`, frame-keyed by `mc.getFrameTimeNs()`. It uses last frame's screen rects (camera tangents)
    and ranks the seated table first, then the looked-at table, then by distance. Plates fade over 150 ms.
  - Each table's board rect is a fixed occupant.
  - `PlateFrame.lastRects()` and `lastHidden()` exist for tests.
- **m11:** `SeatPlates` uses static scratch only. Added `PlateLayout.Scratch`. `PlateRef` is pooled per plate.
- **m12:** `BoardStats` is off unless `-Dburmaldaholic.boardStats=true` or `setEnabled(true)`; when off it writes to a
  sink.
- **m14:** effective FOV comes from `mainCamera().getFov()` (`HoloScale.effectiveFov`).
- **LOD:** hysteresis is now 1 block.
- **Contrast:** added `HoloScale.PANEL`, `MUTED`, `over()`, `contrast()` and `MIN_CONTRAST` (4.5). `HoloText.BACKING` uses
  `PANEL`.
